## Measure first

Boot time is the sum of stages, and each stage has different fixes. Timestamp the serial console from power-on so you can see all of them, including the ones before the kernel prints anything. A typical first measurement (illustrative):

| Stage | Ends when you see | Time |
|---|---|---|
| ROM and SPL | U-Boot banner | 0.4 s |
| U-Boot | `Starting kernel ...` | 3.5 s |
| Kernel | `Run /sbin/init` | 2.1 s |
| Userspace | Your application ready | 6.0 s |

Fix the largest stage first, and measure again after each change.

## Bootloader

The most common waste is the autoboot countdown:

```bash
# U-Boot prompt
setenv bootdelay 0
saveenv
```

With `bootdelay 0` you can still interrupt by holding a key during reset on most configurations; check that on your board before shipping, or you may lock yourself out of the prompt. Also check for slow steps such as probing every storage device or a network boot attempt before the real boot command.

## Kernel

Print each initcall's duration:

```text
# add to the kernel command line (bootargs)
initcall_debug printk.time=1
```

Then sort the slowest:

```bash
dmesg | grep "initcall" | sort -t'=' -k3 -n -r | head
```

Typical fixes: build drivers for hardware you do not have out of the kernel, build drivers needed later as modules and load them after the application starts, and add `quiet` to the command line so the kernel does not spend time printing to a slow serial console.

:::caution[quiet hides problems]
`quiet` lowers the console log level, so a boot failure prints less. Keep it off on development builds.
:::

## Userspace

On systemd images:

```bash
systemd-analyze
systemd-analyze blame | head
systemd-analyze critical-chain myapp.service
```

`critical-chain` shows what your application actually waited for. Often it is `network-online.target` or a slow service it does not really need. Fixes, in order of preference:

1. Remove services the product does not use.
2. Drop unnecessary `After=` and `Wants=` dependencies so things start in parallel.
3. Start the application early and let non-essential services follow.
