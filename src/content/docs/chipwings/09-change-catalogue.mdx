Use this page as a reference when a teammate asks "what did you change in X?". Every row links back to a lesson that explains it.

**Kinds**: **Bug** = upstream code was wrong (also on hardware). **Add** = a piece the design needs that did not exist. **Sim** = Renode only. **Test** = scripts that check the system.

**Board?** says whether the change matters on the Icicle Kit.

## A. Patches to upstream code

These are the changes most worth presenting: each one is a real defect or gap in a third-party project. Each entry gives the file patched, the kind, whether it matters on the board, the lesson that explains it, and what and why.

### NuttX 13.1 (`sw/patches/`, applied by `build-nuttx.sh`)

**0001** `arch/risc-v/src/mpfs/mpfs_timerisr.c` | **Bug** | board: yes | lesson 3
Pass the base `mtimecmp` address. `riscv_mtimer` already adds `8 * cpu_index`, so hart 1 programmed hart 2's timer and never got a tick.

**0002** `arch/risc-v/src/mpfs/mpfs_ihc.c` | **Add** | board: yes | lesson 6
Put the RPMsg resource table first in its struct and in section `.resource_table`, so the linker can pin it at `0xA2300000` where Linux looks.

**0003** `mpfs_ihc.c` | **Bug** | board: yes | lesson 6
Only treat a message as present when its MP bit is set (stale ack and message loop). Retry the notify with a delay and log if it is lost.

**0004** `mpfs_ihc.c` | **Bug** | board: yes | lesson 6
Control register writes that do not mean to consume a message now write MP=1 (`MP_KEEP`). Fixes a read-modify-write race that ate messages.

**0005** `mpfs_ihc.c` | **Bug** | board: yes | lesson 8
Bound the notify retry budget to about 1 ms (it was about a second per failed notification). A dead Linux no longer stalls the sender.

### PX4 (`sw/px4-patches/`, applied once by `build-px4.sh`)

All six matter on the board.

**0001** `platforms/nuttx/cmake/px4_impl_os.cmake` | **Add**
Detect `CONFIG_ARCH_CHIP_MPFS` and choose `microchip/mpfs`.

**0002** `platforms/common/include/px4_platform_common/board_common.h` | **Add**
`PX4_SOC_ARCH_ID_MPFS = 0x000A`.

**0003** `src/lib/controllib/controllib_test/CMakeLists.txt` | **Bug**
Declare the missing `controllib` and `mathlib` dependencies.

**0004** `src/systemcmds/param/param.cpp` | **Bug**
Treat an empty backup file name as "none" (NuttX `open("")` fails with `ENXIO`).

**0005** `platforms/nuttx/CMakeLists.txt` and `platforms/nuttx/NuttX/CMakeLists.txt` | **Add**
Build and link NuttX `openamp/` when `CONFIG_OPENAMP` is set.

**0006** `platforms/nuttx/src/px4/common/tasks.cpp` | **Bug**
Scale task stacks by pointer size. 32-bit stack sizes overflowed on RV64 and corrupted the heap.

### PX4's NuttX fork (12.12), applied by `build-px4.sh`

- **Resource table:** `sw/patches/0002`, the same patch as for NuttX 13.1.
- **IHC fixes:** `sw/px4-patches/nuttx/0003`, `0004` and `0005`: the three IHC patches, rebased for the fork. 0005 uses the real `mpfs` path because `arch/risc-v/src/chip` is a symlink there and git refuses to patch through it.
- **Not applied:** `sw/patches/0001`. 12.12's `riscv_mtimer` adds no per-hart offset, so applying it would break hart 1's tick.

### OpenSBI (`sw/br2-chipwings/patches/opensbi/`)

**0001** `0001-platform-generic-add-Microchip-PolarFire-SoC-Mi-V-IHC-SBI-extension.patch` | **Add** | board: **no**
Adds the Microchip vendor SBI extension (`0x09000029`): IHC init, tx, rx, remoteproc state. Ported from HSS. It also writes MP=1 on control updates (the same race as NuttX 0004). HSS provides this on the board, so it is needed only because Renode skips HSS.

## C. Shared console refactor (committed after testing)

The three scripts below were refactored to remove duplicated socket code and to carry out plan addition A (running the same tests on the board). They were tested on a live Phase 4 simulation before being committed.

| File | Change | Purpose |
|---|---|---|
| `sim/common/cwconsole.py` | New | Shared `Console` class and `--target renode` or `--target board` arguments, taken out of three scripts |
| `sim/phase4/rpmsg_test.py` | Edited | Uses `cwconsole`; gains `--target board` and `--linux-serial` |
| `examples/run_examples.py` | Edited | Uses `cwconsole`; gains `--target board`, `--nsh-serial`, `--linux-serial` |
| `ISSUES.md` | New | Open items (summarised in lesson 10) |

Verified on Renode (`--target renode`, the default): `rpmsg_test.py 500` gave 500/500 round trips, and `run_examples.py` passed 6/6. **The `--target board` path has not run**, because no board or serial device is available yet; test it at H1/H2.
